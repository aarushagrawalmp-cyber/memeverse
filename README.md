# MemeVerse 😂

MemeVerse is a simple meme website where you can browse memes, explore different categories, and create your own memes.

## Features

- Browse different memes
- Explore memes by category
- Search for memes
- Like and save memes
- Create your own memes
- Responsive design

## Tech Used

- React
- Vite
- JavaScript
- CSS
- HTML

## Run Locally

```bash
git clone https://github.com/aarushagrawalmp-cyber/memeverse.git
cd memeverse
npm install
npm run dev
```
